# Cici 三首原创配乐

日期：2026-10-04（America/Los_Angeles）。本轮在《向前一点》上新增《星轨弹跳》《云朵接力》，沿用 TypeScript、原生 Web Audio、Synth、Mixer 与 Sequencer。无新增音频依赖、歌曲录音或外部采样。

## 研究与设计边界

通过 agent-reach 的 Exa 搜索与全文工具重新核对原始研究：

- [Hallam、Price、Katsarou（2002）](https://www.tandfonline.com/doi/abs/10.1080/03055690220124551)，[原始论文全文](https://gwern.net/doc/psychology/music/distraction/2002-hallam.pdf)：31 名 10–11 岁儿童在舒缓背景音乐条件下完成更多分数练习题；准确率差异没有统计显著性。另一项记忆实验提示激烈、不悦的音乐可能干扰表现。这是小样本的特定音乐与任务实验，不能据此承诺新曲提高儿童口算成绩。
- [Cheah 等（2022）系统综述](https://journals.sagepub.com/doi/full/10.1177/20592043221134392)：覆盖 95 篇文章、154 项实验；多数比较没有发现效果，记忆与语言任务总体存在不利影响，歌词比器乐更可能干扰，困难任务也更容易受到影响。综述并非针对本游戏或全部儿童年龄段，不提供统一的最佳速度。

据此采用的设计推论：无歌词；节拍可预测；旋律短句与完整空白小节交替；通过配器丰富程度提供进度反馈；不随答题加速，不添加催促式高潮。100、108、112 BPM 都是作曲选择。音乐音量仍可独立调到零，保留答题音效；全局静音继续覆盖全部声音。不新增按拍答题要求。

## 曲目设计

| 曲目 | 律动与音色 | 和声与旋律 | 乐句 / 渐进试听 |
| --- | --- | --- | --- |
| 向前一点（保留） | 108 BPM，原有切分底鼓、54:46 微摇摆、FM 电钢琴 | C6/9 → Am7 → Fmaj9 → G6sus4，五声音阶短句 | 16 小节约 35.56 秒；54 秒试听 |
| 星轨弹跳（新增） | 112 BPM，直拍四拍底鼓，反拍和弦，八分踩镲力度起伏，短促电钢琴 | C → F → Am → G → C 的和声次序，四组呼应短句；最终阶段每 16 小节 24 个旋律音 | 16 小节约 34.29 秒；53 秒试听 |
| 云朵接力（新增） | 100 BPM，较疏的双落点底鼓、56:44 微摇摆、切分贝斯、柔和木质敲击音色 | C → Am → F → C / Am → F → G → C；旋律隔拍接棒；最终阶段每 16 小节 24 个旋律音 | 16 小节约 38.40 秒；59 秒试听 |

两首新增曲目有不同的鼓、贝斯、和弦落点、和声顺序和旋律；不是原曲换速度。木质敲击音色由正弦基音与较轻的三次分音合成，限制高频，保持原有音效的听觉空间。三首共用 C 调音系，与数字键的 C 大调五声音阶相容；主旋律保持 C4–C5。

每组四小节中，前两小节为旋律短句，后两小节留白。六阶段继续由第 1、5、9、13、16、18 题的进度触发：完整基础律动 → 军鼓 → 铺底 → 辅助打击 → 和弦回应 → 主旋律。新增声部在下一小节边界加入。试听为六阶段各四小节的压缩展示，实际游戏依照答题进度变化。

## 每局随机与生命周期

- `tracks.ts` 维护三首乐谱；每局创建时独立等概率选择，各约 1/3，可连续选到同一首。
- `GameController` 同步选择并捕获曲目，音频初始化完成后只为当前局播放；过期初始化不会播放旧曲。
- 音序器重置时直接采用所选 BPM，避免先以原来的 108 BPM 开始再渐变。
- 暂时切到后台再返回，继续同一曲目、速度、阶段和乐句位置；答题、音量和静音不重新选曲。
- 重新开局停止旧曲排程的音乐声部；退出或胜利先淡出音乐，再停止音乐声部。答题音效属于独立音频总线。
- `music-preview.html` 可选三首、播放/停止、调整音量、下载对应 WAV。切换曲目取消旧播放与旧下载链接；时长、阶段进度和文件名均随曲目更新。游戏与试听调用同一编曲函数。

## 验证入口

`npm test` 覆盖随机区间、每局只选一次、重开、初始化竞态、三首稳定起拍、后台恢复、循环与旋律密度、六阶段试听时长。`npm run build` 包含类型检查与生产试听页。

开发入口 `/tools/focus-check.html` 使用真实浏览器 OfflineAudioContext：三首各六阶段完整 16 小节，44.1/48 kHz、密集音效、静音、BGM 为零时保留音效，以及三首完整渐进试听。数字波形验证能检查静音、后段掉音和数字峰值，不能证明真实设备音量舒适或儿童学习效果。

本轮结果：60 项自动测试通过，类型检查与生产构建通过。真实浏览器中，三首各 10 项乐句/混音检查与完整试听均通过；所有检查的最高数字峰值为 0.471242，没有数字削波。三首试听末尾均归零，后段没有掉音。木质敲击音色与另外 16 项音色/混音检查通过；真实音频图另外验证了旧音乐停止、未来音乐音符取消、答题音效保留。生产页面的三首选择、播放、停止、文件名切换，及游戏的答错重试、答对反击和静音均完成浏览器操作验证。未开展儿童学习效果实验。

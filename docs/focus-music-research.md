# Cici · 数学练习配乐研究与设计

研究日期：2026-10-02（America/Los_Angeles）。目标用户：7–12 岁。目标体验：节奏更有吸引力，音色不幼稚，同时为口算保留思考空间。原始研究通过 agent-reach 的 Exa 网页检索与全文阅读核对。

## 证据能支持到哪里

**音乐可以帮助营造愿意继续练习的气氛，但没有证据证明某首音乐或某个 BPM 能让所有 7–12 岁孩子进入心流。** 本次没有把成人研究、音乐训练效果、或“听着喜欢”直接当成数学成绩提升。

| 原始研究 | 实验对象与任务 | 发现与适用边界 | 本次设计推论 |
| --- | --- | --- | --- |
| [Hallam、Price、Katsarou，2002](https://doi.org/10.1080/03055690220124551)，[论文全文](https://gwern.net/doc/psychology/music/distraction/2002-hallam.pdf) | 数学实验：31 名 10–11 岁学生，15 分钟分数练习；另有 30 名 11–12 岁学生的记忆实验 | 舒缓音乐条件下完成的数学题数量增加；准确率没有显著改善。记忆实验中的激烈、不悦音乐有干扰。样本小，不能直接外推到 7–9 岁或所有音乐风格 | 降低持续的刺激感，以舒服、可预测的伴奏支持练习；不宣称提高准确率 |
| [2026：The effect of background music on children's scientific creativity](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2026.1773321/full) | 实验一：60 名 8–12 岁儿童；实验二：90 名 8–12 岁儿童；科学知识学习与创造任务 | 实验一比较无音乐、76 BPM、119 BPM；慢速音乐更有利于知识保留，快速音乐对创造的流畅性、灵活性、独创性出现不同结果。任务是科学学习与创造，不是口算或心流；只采用一首音乐及速度处理 | “更快、更兴奋”与“更专注、更正确”不能画等号；108 BPM 是兼顾本游戏律动的作曲选择，没有由此实验验证 |
| [Souza 与 Barbosa，2023：Should We Turn off the Music?](https://pmc.ncbi.nlm.nih.gov/articles/PMC10162369/) | 大学生；器乐 lo-fi、带歌词音乐、安静；记忆、阅读与计算 | 歌词对部分认知任务有干扰，计算结果并未给出可靠的歌词损害证据；器乐没有可信的整体促进或损害。不能直接代表儿童 | 使用无歌词器乐以减少语言竞争；“lo-fi”不是有效性的保证 |
| [Thompson、Schellenberg、Letnic，2012](https://doi.org/10.1177/0305735611400173)，[作者机构摘要](https://researchers.mq.edu.au/en/publications/fast-and-loud-background-music-disrupts-reading-comprehension/) | 25 名参与者，快/慢、响/轻四种背景器乐条件，阅读理解 | 快且响的组合会干扰阅读；不是儿童数学实验，也没有给出普适的“最佳 BPM” | 加强节奏的结构与音色，不依靠越来越快或越来越响 |
| [Ulrich 等，2014：Neural correlates of experimentally induced flow experiences](https://doi.org/10.1016/j.neuroimage.2013.08.019)，[原始论文机构记录](https://oparu.uni-ulm.de/items/88eb51c2-fa90-4f40-996a-004334759a77) | 27 名参与者；口算难度按个人能力调整，比较匹配、无聊与过载条件 | 研究通过任务难度与能力的匹配诱发心流，并未测试背景音乐 | 音乐只是环境支持；题目难度、目标和反馈仍然决定练习体验 |

另核对了 [8–12 岁儿童音乐训练与数学表现研究（2026）](https://link.springer.com/article/10.1007/s10212-026-01096-z)：它研究的是音乐训练经历与数学表现的关联，并非做题时播放背景音乐，因此没有据此宣称本配乐能提升数学能力。

对 7–9 岁的直接口算背景音乐证据仍有限；本轮检索未找到足以验证这首原创配乐在该年龄段效果的实验。为此提供独立音乐音量，允许关闭背景音乐并保留答题音效。数字音量不等于耳机或扬声器的实际声压。

## 原创配乐《向前一点》

创作方向是干净的电子律动、轻微 funk 切分和柔和电钢琴，避免儿歌旋律、童声、玩具铃铛和过密的高音。所有声音由 Web Audio 合成，不使用现成歌曲或采样素材。

| 设计项 | 实现 | 用途 |
| --- | --- | --- |
| 速度 | 固定 108 BPM，4/4；整局不随进度加速 | 形成稳定的背景脉冲 |
| 鼓点 | 底鼓在主拍与切分位置，军鼓后拍、力度变化的踩镲、较轻的辅助打击 | 节奏感来自声部关系与动态，而不是提高响度 |
| 微摇摆 | 奇数十六分音符延后一个步长的 8%，约为 54:46 | 让切分有弹性，四分音符主拍保持稳定 |
| 低音 | 五个节奏落点；三角波主体和可在小扬声器听到的二次谐波 | 鼓与贝斯共同带动律动，避免只剩超低频 |
| 和声 | C6/9、Am7、Fmaj9、G6sus4；八小节和声、十六小节乐句 | 温暖、平稳，避免四小节玩具旋律反复 |
| 电钢琴 | 双振荡器 FM、低通、保留音体的衰减、很轻的单次空间反射 | 获得柔和、有质感的音色，鼓组保持清晰 |
| 旋律 | 五声音阶，主要在 C4–C5；完整空白小节；最终阶段的十六小节仅 16 个旋律音 | 留出认知与听觉空间，避免持续抢注意力 |
| 进度变化 | 六阶段保留；新声部在下一小节边界进入 | 答对有音乐反馈，思考途中保持连贯 |
| 开场 | 底鼓、踩镲、贝斯、简化电钢琴已同时存在 | 开局就能听到完整音乐关系 |
| 收尾 | 最后一题保持速度，不再播放催促式 riser | 减少突然刺激；胜利保留短结局反馈 |
| 音量 | 游戏背景音乐默认 75%，可独立调到零；全局静音仍有效 | 支持不同偏好；音效与背景音乐可分开控制 |

**54 秒试听是六段编曲的压缩展示**：每四小节换到下一阶段；实际游戏依照答题进度换阶段，慢慢思考时不会因试听时间表而增加配器。试听与游戏调用同一个 `arrangeStep` 与合成器，没有另做一段录音充当游戏音乐。

## 技术依据与验证边界

- [MDN OfflineAudioContext](https://developer.mozilla.org/en-US/docs/Web/API/OfflineAudioContext)：以真实浏览器音频图渲染试听、波形与 WAV，避免用另一套数值合成代替产品声音。
- [MDN AudioContext.resume](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume)：实时音频在用户手势中创建与恢复。
- [MDN cancelAndHoldAtTime](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/cancelAndHoldAtTime)：该接口并非所有主流浏览器通用，本次渐变使用基础 AudioParam 调度。

波形检查可以验证静默、连续性、数字峰值和有限尾音，不能证明专注提升、心流或实际设备听感。当前仍需真实儿童在相同难度下比较有音乐/无背景音乐的练习；应关注一次答对率、重试、主动继续与“是否分心”，不能只看做题变快。7–9 岁与 10–12 岁宜分别观察，并轮换测试顺序。

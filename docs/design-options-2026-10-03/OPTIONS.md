参考：[grmchn/dopa-drill](https://github.com/grmchn/dopa-drill)，本次读取提交 `fdacd5fc8322f251f92ddc07f13ae85ccb2263dd`。通过 GitHub CLI 获取源码，在内置浏览器实际操作一年级模式，记录开局和第 8 题的舞台。

- [参考开局截图](./reference-playing-early.jpg)：奶油色方格纸、深靛蓝轮廓、大数字、角色舞台、清晰的题卡与数字键。
- [参考后段截图](./reference-playing-late.jpg)：完成 7 / 10 题后，彩色放射背景、彩旗、观众、纸屑和连击反馈明显增强，题卡仍为稳定的白色阅读区。

关键交互差异由源码与实机共同确认：参考项目每输入一位数字就即时判定，角色搬运该位数字，最后一位正确后自动换题；调整前的 Cici 输入完整答案后按发射。三套初稿围绕这个差异展开，分别改变输入、画面布局和奖励方式。

每次生成均附上以上三张真实截图。参考用于 UI 语言、反馈节奏与舞台变化；Cici 的博士、机器与实验器材采用原创设计。

## 数字搬运舞台

[完整效果图](./concept-01-digit-carry.png)

- 一张大题卡搭配三列数字键，博士位于题卡侧边，桌面空间用于数字移动和角色演出。
- 输入数字时先显示该位判定，再播放博士接住、搬运、放入题格的动作。正确位保留，错误位可重新输入；不会把已正确的前一位清掉。
- 完成一道题后出现短庆祝并进入下一题。每几个答案增加彩旗、试管观众和场景色彩，最终形成完整庆典。
- 20 题实验进度替代当前对博士的生命值攻击。博士从 Boss 转为陪伴角色，继续保留原创紫发和薄荷眼镜特征。
- 图中 `8 + 7 = [1][?]` 展示十位已确认、正在搬运个位数字 5 的状态。

## 泡泡发射实验台

[完整效果图](./concept-02-bubble-launch.png)

- 横向实验室战场：博士与泡泡发射机在左，实验目标机在右，数学题与按键在前景工作台。
- 输入完整答案时，操作台题格和发射口泡泡同步显示答案。点击「发射答案」或按 Enter 后，泡泡沿明确弹道移动，命中目标并推进实验。
- 每完成一段，目标机和实验室增加新的表现；连击强化泡泡大小、命中环和局部庆祝，不增加需要记忆的额外操作。
- 答错时泡泡弹回工作台，提供温和重试与可选提示。已完成题目、音乐层次和场景进展保留。
- 保留现有完整答案提交规则；实验目标机承担原有 Boss 进度，博士成为发射搭档。
- 图中 `8 + 7 = 15` 展示答案已装填、等待发射的状态。

## 节奏庆典实验室

[完整效果图](./concept-03-music-festival.png)

- 大横向实验室音乐舞台，博士担任指挥，烧瓶、试管和圆瓶化为原创乐器助手。
- 数字键采用两排五列；每个数字带有音色，输入后数字沿短轨迹进入题格。末位答对后产生一次明确的合奏庆祝。
- 六个舞台乐器标记直接对应现有六阶段音乐。逐步加入乐器、灯光、观众和彩旗，最终以全实验室庆典结算。
- 节拍用于舞台呼吸和庆祝；玩家可以按自己的速度思考。阶段进展不因答错倒退。
- 博士从被攻击对象转为庆典指挥。阶段目标以点亮实验室和完成 20 题呈现。
- 图中 `8 + 7 = [1][?]` 展示数字 5 从按键进入题格的瞬间；四个乐器已亮起。

## 三套共同保留与增加的内容

保留 Cici 品牌、原创博士特征、20 以内加减法、20 题闭环、数字音效、现有音乐基础、静音、独立音乐音量、减少动态、触屏与键盘操作、结算与重开。

增加可选的拆分提示，例如 `8 + 7 = 8 + 2 + 5`。提示需通过点击显示，不自动透露完整答案。三套均有点击与键盘等价操作；不要求拖拽、抢答或按拍作答。

桌面充分利用横向空间；手机按舞台、题目、按键依次排列。数字搬运与发射动作随布局使用实际起点和终点，减少动态模式以局部高亮替代大幅移动。

## 选定后的实施顺序

1. 以选定图片为视觉目标，拆出博士、机器、舞台和反馈素材；实现桌面与手机的场景结构。
2. 按该方案改造输入与判定，并将数学状态和动画状态分开。连续输入不等待搬运动画；旧一局的回调不能影响新一局。
3. 把已完成题目、阶段变化和六层音乐接到同一个进度来源，完整实现答题、重试、庆祝、结算与重开。
4. 验证连续键盘输入、触控、多位数字、删除、提示、错误重试、阶段切换、静音、减少动态、20 题结束和重开。

生成图中的点阵和小仪表用于视觉示意。实现时，题号、进度点、目标机进度和乐器阶段会统一由真实题目进度驱动。运行时的控件会由代码实现，不把整张视觉稿作为页面贴图。

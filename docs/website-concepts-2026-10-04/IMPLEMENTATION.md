# 第 3 版：钴蓝游戏场

用户选择本次实际展示的第 3 张 `cobalt-playground.png`，授权开始制作，并增加悬停放大、动效与打卡组件。实现复用原 React / Vite 项目与两个实际游戏。

## 完成的页面与交互

- 钴蓝弧面首屏、两行大标题、浅色内容画布；Geist 拉丁字体与 Noto Sans SC 中文可变字体本地加载。
- 品牌吉祥物透明素材用于导航、首屏、学习章节和浏览器图标。首屏包含入场、浮动、鼠标轻微跟随和滚动视差。
- 两个游戏入口保留实际游戏封面和内容。鼠标悬停时「开始游戏」放大 6%，箭头移动，封面放大 5.5%，桌面双列轻微展开。键盘聚焦有清晰轮廓。
- 学习回顾分为本局成绩、错题回顾、下一局建议；可点击标签、前后按钮或使用左右方向键 / Home / End。口算示例支持展开、收起凑十思路。
- 每日打卡显示本周七天、连续天数、实际完成局数；每周目标可选 3 / 5 / 7 天。手动打卡反馈包含小幅弹性缩放和少量蓝色星光。
- 完成一局且至少判定一道题，自动打卡并更新实际局数、最近玩的游戏。相同 sessionId 不重复记账；同一天不重复打卡。
- 首页、大厅、游戏页面使用一致导航；手机菜单支持展开、点选关闭、Escape 关闭和外部点击关闭。

打卡和游戏足迹保存在当前浏览器设备，未增加登录或跨设备同步。存储被阻止时，手动打卡保留在当前页并提示保存限制。减少动态效果设置会关闭 GSAP 入场、跟随和固定效果，并缩短 CSS 动画。

## 主要实现

`src/arcade/HomePage.tsx` 组织首页；`useHomeMotion.ts` 管理滚动与首屏动效；`GameCards.tsx` 保留实际游戏入口；`LearningSection.tsx` 实现学习标签和示例；`DailyCheckIn.tsx`、`activity.ts`、`useActivity.ts` 负责打卡与持久化；`SiteChrome.tsx`、`MotionLink.tsx` 负责导航与按钮。原有 iframe 通信验证和学习总结接口继续使用。

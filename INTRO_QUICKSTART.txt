🚀 三步使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  查看预览 (正在运行)
    → 打开浏览器访问 http://localhost:3002
    → 拖动时间轴，查看8秒完整动画

2️⃣  渲染视频
    → npm run intro:render
    → 等待1-3分钟
    → 生成 public/intro.mp4

3️⃣  集成到游戏
    修改 src/main.tsx:

    import AppWithIntro from './AppWithIntro'

    createRoot(document.getElementById('root')!).render(
      <StrictMode>
        <AppWithIntro />
      </StrictMode>,
    )

🔧 快速调整
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

改时长      Root.tsx → durationInFrames
降低质量    npm run intro:render -- --quality=70
小分辨率    npm run intro:render -- --width=1280 --height=720
减粒子      ParticleSystem.tsx → count = 200

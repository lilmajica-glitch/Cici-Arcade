🎬 霓虹跑酷 Intro 视频

8秒确定性开场动画 · 霓虹紫色 · 赛博跑酷风格

📋 视频信息

  • 时长: 8秒 (480帧 @ 60fps)
  • 分辨率: 1920x1080
  • 主色调: 霓虹紫色 (#a855f7)
  • 技术栈: Remotion + Three.js + React

🎬 分镜说明

0-1.5s: 鞋子出现
1.5-3s: 脚踝旋转热身
3-4s: 蓄力停顿，地面发光
4-5.5s: 爆发起跑，粒子拖尾
5.5-7s: 显露三条霓虹赛道
7-8s: 冲入光门过渡

🚀 如何渲染

如果视频文件不存在，请运行：
npm run intro:render

或者在Remotion Studio中实时预览：
npm run intro:preview

  步骤 2: 渲染视频

          ↓

  步骤 3: 集成到游戏
  ┌─────────────────────────────────────────────────────────┐

  │   import AppWithIntro from './AppWithIntro'            │
  │                                                         │
  │   createRoot(root!).render(                            │
  │     <StrictMode>                                        │
  │       <AppWithIntro />                                  │
  │     </StrictMode>                                       │
  │   )                                                     │
